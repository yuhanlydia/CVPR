## 数学与实际代码

### I03：明确的评分表达式缺口

代码 `fit(I03)` 得到正半定矩阵 M；`features` 返回 qM 与 c，
评分入口调用点积。因此实际分数是 qᵀMc。

距离目标是：

```text
-(q-c)^T M(q-c) = 2 q^T M c - c^T M c - q^T M q.
```

固定 query 时，最后一项可省，但候选范数项 cᵀMc 不能省。
原始 q/c 的欧氏单位范数不保证各候选的 M 范数相同。
已有 I03 卡明确记录此问题；当前汇总用的是仍未修复的历史代码。
这证明实现不匹配该距离构造，不证明修复后会提高成绩。

后续最小检查是冻结同一个训练头、PCA、样本与原生候选，
比较历史点积和完整距离排名，保留候选范数变化及原始预测。
这是改变评分的 child protocol，不能覆盖或重标当前 16.7% 为修复结果。
同维度强对照与完整 G01/Local 接受仍需补齐。

### I16：精确核的排名等价已限定解释

对当前经过 `unit` 的 q/c，且 sigma>0：

```text
||q-c||^2 = 2 - 2 q^T c
k(q,c) = exp((q^T c - 1)/sigma^2).
```

指数严格单调，所以精确 RBF 与点积排序相同；表中 C_RBF 和
C_PROJECTED 相同与这个恒等式一致，原始排序与 ties 尚待核验。
Nyström 的正则近似改变的是原有排序。22.4% 的结果反映当前近似后的损失，
不能解释为“精确非线性核本身可以改善这些单位输入的排序”。
若未来有收益，需归因并比较近似/正则作用和完整成本；不能靠核名称宣称表达力提升。
当前没有理由为“精确 RBF 质量更好”进行盲目参数搜索。

### I10/I12：异常低分的原因仍待检验

I10：代码执行训练配对的中心化、两侧白化与 cross-SVD，保留 16 个方向；
返回后没有把两侧特征重新单位化。CCA 优化相关性，不保证检索排名最优。
32维普通白化与16维 CCA还混合了维度变化。应先检查现有头的谱、变换范数、
原始排名以及同维度控制，不能直接断言“忘记归一化导致全部降分”；
改变归一化会改变构造，必须单独版本化。

I12：有限图外推中的 lambda^(t-1) 与已有卡的推导一致。
实际评分是扩散坐标的点积，不是坐标欧氏距离。
原论文讨论的是扩散嵌入后的欧氏距离与扩散距离的关系
（[原文](https://arxiv.org/pdf/math/0503445)，相关页为 PDF 第11页）；
坐标点积不自动继承这一性质。
当前 1.667% 是严重异常，但还缺坐标范数、谱、实际任务候选、
逐样本排名及运行版本证据。候选范数偏置、信息丢失和训练图外推失配是竞争解释，
没有已验证的唯一根因。原有卡已经按实际点积构造限定了声明，不能直接把它当成新的代码 bug。

### I02/I17：理论条件不是整任务保证

I02 的不变式只对固定 R 的 span 内 query 的原始分数成立。
配置为 protected_rank=8，而压缩空间为32维。
还需核对实际约束残差与 query 距该 span 的量；整个任务 hit@1 下降
不单独证伪那个线性代数不变式，但当前结果没有支持实用保护收益。

I17 的独立、加性、等方差噪声假设需要原始特征矩支持。
非线性单位归一化不能自动保留这些假设。
单侧 LMMSE 系数 r 也不等于最优检索分数；两侧去噪乘积会含 r²，
历史实现采用 diag(r)。已有 I17 卡将检索构造标为 PARTIAL。
41.5% 仅是该启发式的开发成绩，不是完整噪声理论的验证。

### I05/I11/I14：没有增量、弱收益与优化证据缺失

I05 有多正例 guard，但只要求至少一行有多个正例。
真实多正例占比、正例权重与覆盖尚未返回。
当每行只有一个正例时，其 inside-log 目标与 single-positive 目标相同；
多个正例时，梯度使用 positive-only softmax，容易正例可以占主导。
C_SINGLE 还改变了其他已知正例的处理；现有比较不能替代公平的 outside-log SupCon 对照。
+0.033 个百分点不构成多正例机制收益的证据。

I11 对 ScienceQA/A-OKVQA 的训练来源损失做 softmax 加权，
不直接优化三项测试任务的最差组。
三项 hit@1 相同说明当前端点未观察到 ERM 之上的增量。
缺训练组损失/权重/实际头差异与完整排名，不能判断是权重几乎一样、
训练变化没有翻转排名，还是在当前任务上机制不适用。
“平均持平”也不能替代最差组评价。

I14 的 Huber IRLS 有有限12步上限。已有代码会记录更新范数，但汇总没有提供。
ChartQA 相对 C_KD +1.2、COCO +1.0、ScienceQA -0.1，均分 +0.7；
C_KD 本身比不更新基线低5.47点，I14仍没有恢复该损失。
须检查实际残差、截断权重和收敛证据，不能把弱基线上的提升解释为成功。

I09 同样需要审查：一次 Fisher-floor 二阶近似只对局部模型有解释；
代码记录 true CE before/after 和最大 logit step，汇总没有给出。
历史 C_KD 是平方间隔拟合，与 I09 的 soft-target CE 不同。
需要同目标、同数据与完整成本的优化对照才能把优势归因于曲率。
